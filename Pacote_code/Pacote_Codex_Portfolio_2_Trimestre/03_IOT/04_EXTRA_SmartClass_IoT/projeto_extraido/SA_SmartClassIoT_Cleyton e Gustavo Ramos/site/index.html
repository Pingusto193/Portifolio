SmartClass IoT

Sistema Inteligente de Monitoramento da Temperatura da Sala

Problema Projeto Componentes Resultados

Problema

Muitas salas de aula apresentam temperaturas elevadas, causando desconforto aos alunos e professores. Sem um sistema de monitoramento, a decisão de ligar ventiladores ou abrir janelas depende apenas da percepção das pessoas.

Sobre o Projeto

O SmartClass IoT utiliza um Arduino Uno, um sensor de temperatura e um LED para monitorar o ambiente. Quando a temperatura ultrapassa 28°C, o LED acende indicando uma situação crítica.

Componentes Utilizados

  • Arduino Uno
  • Sensor TMP36
  • LED Vermelho
  • Resistor 220Ω
  • Protoboard
  • Jumpers

Funcionamento

  1. O sensor mede a temperatura.
  2. O Arduino processa o valor.
  3. O Monitor Serial mostra a temperatura.
  4. Se a temperatura passar de 28°C, o LED acende.
  5. Caso contrário, o LED permanece apagado.

Resultados dos Testes
